The delivery includes WebGPU and WebGL2 source, shader initialization diagnostics, integer/RGB ID passes and readback code, but their execution is **not validated by these results**. Export checks read generated HTML/CSV/project Blobs. They test the content and application action, not an operating-system file-save dialog. The HTML report generated by this workflow is [included here](sample-coordination-report.html).

## Actual geometry outcomes

The built-in Structure vs. Mechanical test evaluates 32 candidate pairs and reports 32 contact/intersection results. A second unchanged run evaluates zero new pairs and reuses all 32 cached results while retaining the approved review status. The MEP clearance test finds 12 qualifying pairs at a 150 mm threshold; its results include computed **110 mm** surface gaps.

The supplied GLB fixture adds 3 elements; the supplied native IFC fixture adds 4. The browser integration test federates them with the original 143 entities, then exports and restores the resulting **150-entity** project with its issue and measurement intact.

No performance extrapolation to very large models is implied. The baseline screenshot visibly identifies the software backend. GPU performance and deployment-grade capacity need measurement on target hardware and representative models.

## Not covered

Actual WebGPU/WGSL or WebGL2/GLSL execution; GPU ID readback; full web-ifc installation and broad IFC geometry; IndexedDB persistence across a real-origin browser reload; large imported BIM benchmarks; Safari/Firefox/mobile-device behavior; long-running multi-model memory-pressure tests; mathematically exact Boolean/containment certification.

## Re-run on target hardware

Serve the modular app with `npm start`, then run `scripts/browser-smoke.py --browser /path/to/chromium --url http://localhost:8080` in a fresh profile. The script reports the selected renderer and storage availability. Separately verify IndexedDB by saving, closing the browser, reopening the same origin and checking the restored project. Install the optional IFC dependency first and test representative files, including openings, placements, units, repeated geometry and large coordinates.
